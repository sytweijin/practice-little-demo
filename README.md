# 在场 — AI 记忆工坊

在场是一款本地运行的个人记忆整理工具。它把参访、展览、会议、课程、旅行中随手拍下的照片、录下的音频、记下的文字交给 AI 提炼，生成可以长期保存和复习的"记忆卡片"。

工具的核心分工是：AI 负责筛选和提炼素材，用户负责确认和补充意义。AI 生成的卡片会先进入草稿区，由用户确认后才进入记忆库。每张卡片是否参加回忆挑战，也完全由用户自己决定。

## 产品定位：人与智能认知

这个产品围绕"人与智能认知"这一主题展开，想回答一个具体的问题：当 AI 已经能帮我们记录、整理、甚至发现关联时，人的认知角色还剩下什么？

出发点是一个日常矛盾。我们参加展览、走访企业、听一堂课、走一段路，注意力是有限的。要么全心投入当下、事后遗忘大半；要么忙于拍照记笔记、反而错过了正在发生的事。"在场"这个名字指向的就是这个困境——我们希望人在现场时是真正在场的，而把素材的筛选、提炼、排期交给机器。

但这不意味着把认知外包出去。产品里有一条贯穿始终的原则：**AI 负责提议，人负责决定。** AI 把照片、录音、文字整理成草稿卡片，但只有经过用户确认才进入记忆库；AI 能发现跨场景的关联，但用户可以选择锁定或清除；AI 能生成月度回顾，但用户可以随时删除重写。人的角色始终是意义的赋予者，而不是 AI 输出的被动接收者。

回忆挑战把认知科学里的一个朴素道理落地：记忆的关键不在于存储，而在于反复提取。这部分完全由人完成——先默写、再揭晓、再判断难易。AI 帮你把值得复习的内容挑出来，但真正"记住"这件事只有靠你自己。

一句话：AI 扩展了记忆的容量和整理效率，人保留了判断什么值得记住的特权。这是我们对"人与智能认知"关系的一种回答。

## 一、功能总览

### 1. 素材采集与 AI 提炼

支持照片、视频、录音、文本文件混合上传，也支持直接输入文字备注。AI 会根据场景判断哪些内容值得长期保留，并把素材整理成标题、摘要、标签齐全的卡片。

### 2. 三种记录模式

- 深度模式：AI 分析后先生成草稿，用户逐个确认、编辑或跳过。
- 快速模式：上传后直接生成并自动保存卡片，适合信息量小的记录。
- 隐私模式：完全在本机生成占位卡，不调用云端 AI、语音识别和视觉模型，适合敏感内容。

### 3. 记忆库

记忆库按文件夹组织卡片，支持场景筛选、日期筛选、多关键词搜索、批量移动和批量删除。卡片详情页可以编辑内容、管理标签、删除卡片，也可以把卡片生成图片分享出去。

### 4. 回忆挑战

用户可以单独为某张卡片开启回忆。开启后，卡片会按照间隔重复算法进入复习队列，复习时先默写、再揭晓，并根据"简单、中等、困难"调整下一次复习时间。

### 5. 认知账单

账单记录素材数量、生成卡片数量、AI 实际处理时长、快速模式与深度模式的次数、回忆投入时间和完成情况。估算节省时间仅作为参考，实际处理时长按真实调用计时。

### 6. 时间线与月度回顾

日历视图按日期展示记忆卡片。每个月可以生成一篇月度回顾，把当月记忆整理成叙事文本。

### 7. 记忆星图

3D 星图用标签节点展示记忆之间的关系。深粉色线是共享标签联结，悬停时变浅粉色；青色线是 AI 发现的联结，白色线表示已锁定的联结。AI 可以发现跨场景联结，用户可以选择锁定或清除这些联结。

### 8. 多档案

工具支持多个独立档案。每个档案使用独立的数据库文件，适合同一台电脑由多人使用，或一个人按不同项目分开管理。

### 9. 数据备份与恢复

一键导出完整备份压缩包，压缩包内包含卡片数据、叙事、联结、文件夹和全部媒体文件。导入备份时可以智能合并，按"标题 + 日期"识别已有卡片，保留更新的内容和较高的回忆进度。

### 10. PWA 支持

网页可以安装到手机主屏幕，安装后支持离线打开，并可以从系统其他应用接收分享的图片、视频或文字。

## 二、运行环境

- Python 3.9 或更高版本
- 支持摄像头、录音的现代浏览器（推荐 Chrome 或 Edge）
- 如需手机访问，电脑和手机需要连接同一个 WiFi

## 三、快速开始

### 第一步：安装依赖

在项目目录下打开终端，执行：

```bash
pip install -r requirements.txt
```

### 第二步：配置 AI（可选）

不配置 AI 也可以使用工具，此时会生成占位卡片，由用户手动补充内容。配置后，AI 才能完成素材分析和提炼。

复制环境变量示例文件：

```bash
cp .env.example .env
```

推荐使用阿里云百炼的 DashScope Key。编辑 `.env`，填入：

```ini
DASHSCOPE_API_KEY=你的Key
```

视觉理解路径使用多模态模型 `qwen3.7-plus`（可用 `DASHSCOPE_VISION_MODEL` 覆盖）。语音识别使用 `paraformer-v2`（`DASHSCOPE_ASR_MODEL`），文本模型默认使用 `qwen-plus`（`DASHSCOPE_TEXT_MODEL`），这些都可以在 `.env` 中按需覆盖。

如果使用 OpenAI 兼容接口，可以配置：

```ini
OPENAI_API_KEY=你的Key
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_VISION_MODEL=gpt-4o
OPENAI_TEXT_MODEL=gpt-4o-mini
```

修改 `.env` 后需要重启服务。重启方式是先按 Ctrl+C 停止当前进程，再重新执行 `python main.py`。

### 第三步：启动服务

在项目目录下执行：

```bash
python main.py
```

程序会自动生成或复用本机 HTTPS 证书，并输出访问地址：

- 电脑访问：`https://127.0.0.1:8001`
- 手机访问：`https://电脑局域网IP:8001`

手机第一次访问时，浏览器会提示证书不受信任，这是自签名证书的正常提示。请点击"高级"，再选择"继续访问"。

### 第四步：安装到手机（可选）

用 Chrome 或 Edge 打开网页后，在浏览器菜单中选择"添加到主屏幕"。添加后可以从主屏幕图标打开应用，并支持接收系统分享的内容。

## 四、操作指南

### 1. 选择场景

采集区上方可以选择场景。内置五个场景：博物馆 / 展览、企业参访、会议 / 讨论、课程 / 讲座、旅行 / 行走。点击"＋ 自定义"可以新建场景并自行命名、选择图谱颜色；之后点击场景上的编辑按钮可以重命名、改色或删除。删除自定义场景时，该场景下的卡片会移回"自定义"。场景会影响 AI 的筛选标准和记忆卡片的内容重点。

### 2. 上传素材

点击上传按钮，可以选择照片、视频、录音或文本文件。也可以直接在文字备注框里输入内容。多个素材可以同时上传，AI 会一起分析。

### 3. 生成记忆卡片

确认场景和素材后，点击"生成记忆卡片"。

AI 分析完成后，页面会出现草稿卡片。每张草稿都有三个操作：

- 确认保存：把卡片正式写入记忆库。
- 编辑：先修改标题、摘要、标签等内容，再保存。
- 跳过：删除这张草稿。

只有经过确认的卡片才会进入记忆库。AI 生成的内容只作为提案，最终是否保留由用户决定。

### 4. 使用快速模式

如果希望跳过筛选步骤，可以打开"一键记录"开关。此时上传素材后直接点击生成，卡片会自动确认保存。快速模式适合事后补记、素材内容简单、或用户希望全部保留的情况。

### 5. 使用隐私模式

打开"不调云端"开关后，系统不会把素材发送给云端 AI，也不会调用云端语音识别和视觉模型。上传的素材会在本机生成占位卡片，卡片的标题、摘要和意义需要用户自行补充。

隐私模式适合记录敏感内容，或网络环境不允许访问云端服务的情况。

### 6. 管理记忆库

在记忆库页面可以：

- 按文件夹查看卡片，也可以查看未分类卡片。
- 按场景或日期筛选卡片。
- 在搜索框输入关键词，搜索会匹配标题、摘要、个人归因、标签和素材来源文字。
- 勾选多张卡片后批量移动文件夹或批量删除。
- 点击卡片查看详情，详情页可以编辑、删除或分享为图片。

### 7. 管理标签

在记忆库工具栏点击"标签管理"，可以查看每个标签下的卡片数量，也可以重命名或删除标签。删除标签后，该标签会从所有卡片上移除。

### 8. 使用回忆挑战

回忆挑战默认不自动开启。用户在卡片详情页打开"回忆"开关后，该卡片才会进入复习计划。

复习时，页面会先让用户默写或回忆卡片内容，再点击揭晓查看答案。用户根据回忆效果选择"简单、中等、困难"，系统会按 1 天、3 天、7 天、14 天、30 天递增间隔安排下一次复习。

如果浏览器询问通知权限，可以选择允许。这样当天有到期卡片时，页面会在后台收到提醒。

### 9. 查看认知账单

在账单页面可以看到累计素材数、生成卡片数、AI 实际处理时长、快速 / 深度模式次数、回忆投入时间、回忆完成率等数据。这些数据用于帮助用户了解自己的记忆整理投入，不参与评分。

### 10. 查看时间线与月度回顾

日历页面按月份展示每天是否有记忆卡片。点击某一天，可以查看当天的全部卡片。

点击"生成本月回顾"后，AI 会把当月记忆整理成一篇叙事文本。生成后可以随时删除重新生成。

### 11. 查看记忆星图

在星图页面，记忆卡片按标签关系在三维空间中展示。深粉色线表示共享标签联结，悬停时会变成浅粉色；青色线表示 AI 发现的联结，白色线表示已锁定的联结。用户可以锁定重要的联结，也可以清除不需要的联结。

### 12. 使用多档案

页面右上角可以切换档案。新建档案时，新档案从空开始，不会复制演示数据。每个档案的数据相互独立。

适合的使用方式包括：

- 同机多人各建一个档案。
- 一个人按不同项目、不同阶段分开管理。
- 将工作记忆和私人记忆分开存放。

### 13. 备份与恢复

导出完整备份：

在记忆库工具栏点击"完整备份"，浏览器会下载一个 `.zip` 文件。文件内包含 `snapshot.json` 和所有引用的媒体文件，可以完整迁移到另一台设备。

导入备份：

点击"导入备份"，选择之前导出的 `.zip` 文件，或选择 JSON 备份文件。导入时会执行智能合并：按"标题 + 日期"匹配已有卡片，更新更新的内容，保留较高的回忆进度。

CSV 导出：

如果需要把卡片导入 Anki 等外部工具，可以请求接口 `/api/export?format=csv`。该接口返回带 BOM 的 CSV 文件，包含 Front、Back、Tags 等字段。

### 14. 使用系统分享

应用安装到手机并授予分享目标权限后，在其他应用中点击"分享"，把图片、视频或文字分享给"在场"。回到应用后，分享的内容会自动进入采集区。

## 五、常见问题

### 1. 没有配置 API Key 能使用吗？

可以。未配置 Key 时，系统生成占位卡片，用户需要手动补充卡片内容。配置 Key 后，AI 才执行真实分析和提炼。

### 2. 页面提示 AI 调用失败怎么办？

页面会显示具体失败原因。常见原因包括：Key 无效、模型名称不正确、网络无法连接、云端处理超时。请检查 `.env` 配置和网络后重启服务。

### 3. 为什么手机无法访问？

请确认手机和电脑连接同一个 WiFi，并使用启动时打印的局域网地址。如果手机提示证书不受信任，请点击"高级"并选择"继续访问"。如果仍然无法打开，请检查电脑防火墙是否放行 8001 端口。

### 4. 启动时报端口被占用怎么办？

说明 8001 端口已被其他进程占用。请先停止旧的在场服务进程，或关闭占用端口的程序，再重新执行 `python main.py`。

### 5. 隐私模式会把素材上传吗？

不会。隐私模式不调用云端 AI、语音识别和视觉模型，素材只在本机生成占位卡片。

### 6. 数据保存在哪里？

数据库保存在 `data/` 目录。默认档案是 `memory.db`，其他档案是 `memory_档案名.db`。上传的媒体文件保存在 `static/uploads/` 目录。

### 7. 单个文件有大小限制吗？

单次上传的每个文件上限为 512MB。超过上限时，系统会返回"文件过大"的提示，不会继续处理。

### 8. 上传的媒体文件会一直保留吗？

不会。每次启动服务时，系统会清理 `static/uploads/` 中未被任何档案引用且超过 7 天的文件。已经生成卡片引用的素材会一直保留。

### 9. 多人一起使用安全吗？

工具默认没有登录鉴权，同一局域网内的其他设备可以访问。它适合可信的家庭网络或内部网络，不要直接暴露到公网。

## 七、使用边界

- 回忆开关默认关闭，用户按需开启。
- AI 只生成标题、摘要和标签，不代替用户填写"个人归因"。
- 卡片确认后才能进入记忆库，快速模式属于用户主动选择的后门。
- 完整备份包含全部数据和媒体文件，请注意保管。
- 单次上传的每个文件上限为 512MB。
- 启动服务时会自动清理未被引用且超过 7 天的上传文件。
- 服务默认不自动重载代码；开发时如需热重载，可设置 `PRESENCE_RELOAD=1`。
- 自签名 HTTPS 证书仅适用于本机与局域网，不适用于公网部署。

## AI 使用披露

本项目是一个以 AI 为核心能力的实践作品，AI 的使用体现在两个层面：

- 产品功能层面：工具通过阿里云百炼（DashScope）或 OpenAI 兼容接口调用大语言模型，完成图片与视频的视觉理解、语音转写、记忆卡片提炼、跨场景关联发现和月度回顾生成。这些都是产品本身的功能，用户在上传素材时会感知到 AI 的参与，也可以通过隐私模式完全关闭云端调用。
- 开发过程层面：本项目的部分代码借助 AI 辅助编程工具完成编写与调试，包括前后端实现、样式调整和文档撰写。所有设计决策、功能取舍和主题立意均由作者做出，AI 仅作为实现过程的辅助工具。
